# K0RE - Advanced Intelligence Ecosystem

## Brand
- AI = "Advanced Intelligence" (NOT Artificial)
- Core slogan: "Dreaming Reality™"
- Colors: Black (#0A0A0A), Gold (#C9A84C), Silver (#A8A9AD)
- All pricing ends in 8

## Architecture
- 3 Supabase projects: Command Center, Trillium, Arterial
- 12 AI agents orchestrated via heartbeat edge function
- Cross-project credentials stored in ops_config table
- See docs/master-plan.html for full specification

## Tech Stack
- Frontend: Next.js 15, Tailwind, Framer Motion
- Mobile: React Native (Expo)
- Desktop: Tauri (Rust + React)
- Backend: Supabase (Edge Functions, Auth, Realtime)
- Payments: Stripe (Billing, Connect, Checkout, Invoicing)
- Design system: Black/Gold/Silver, Inter font, premium aesthetic

## Key Rules
- Reference wireframes in docs/ for all UI decisions
- Use Tesla/Apple-level design quality
- Every component must feel premium and intentional
